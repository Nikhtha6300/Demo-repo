# Kruti-style Explore UI (static)

This is a static HTML/CSS/JS implementation of the "Explore Kruti" UI shown in your screenshot.

## Run locally

From the repo root (or open a terminal in Cursor):

```bash
python3 -m http.server 8000 --directory /workspace/kruti-ui
```

Then open the served URL on port 8000. In Cursor, a preview should appear automatically when the server starts.

Files:
- `index.html` – structure
- `styles.css` – styling
- `script.js` – search + category filtering
